# Homeworks - JavaScript

Repositorio de tareas de JavaScript. Cada carpeta corresponde a un tema y contiene ejemplos ejecutables.

## 01 - Arrays

La carpeta `01-Arrays` incluye un ejemplo independiente de cada método o propiedad estudiada de `Array`.

### Ejecutar un ejercicio

Se necesita Node.js 18 o superior. Desde la raíz del repositorio:

```powershell
node .\01-Arrays\01-at.js
```

Reemplaza el nombre del archivo por el ejercicio que quieras ejecutar.

## Contenido

`at`, `concat`, `copyWithin`, `entries`, `every`, `fill`, `filter`, `find`, `findIndex`, `findLast`, `findLastIndex`, `flat`, `flatMap`, `forEach`, `includes`, `indexOf`, `join`, `keys`, `lastIndexOf`, `length`, `map`, `pop`, `push`, `reduce`, `reduceRight`, `reverse`, `shift`, `slice`, `some`, `sort`, `splice`, `toLocaleString`, `toString`, `unshift` y `values`.
